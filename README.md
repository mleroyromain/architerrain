# ArchiTerrain Web V1

Prototype PWA mobile.

## Tester sans installation
Ouvrir `index.html` dans un navigateur moderne.

## Mettre en ligne
Héberger le dossier sur un hébergement HTTPS statique. Une fois en ligne, ouvrir l'URL sur iPhone avec Safari puis **Partager > Sur l'écran d'accueil**.

## Important
Cette V1 affiche une analyse de démonstration structurée. La prochaine étape est de brancher le backend réel sur :
- API Carto Cadastre IGN
- API Carto Urbanisme / GPU
- Géorisques
- données patrimoniales

Le produit est volontairement prudent : il ne transforme pas une information communale en conclusion parcellaire.
